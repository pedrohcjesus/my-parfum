|---|---|:-:|:-:|---|

## Guia rápido: qual usar quando

| Situação | Use | Por quê |
|---|---|---|
| Dia quente, rua, casual | **Verde** | Fresco e presente |
| Dia muito quente, academia, pós-banho | **Rosmarino** | Leve e reaplicável |
| Escritório, reunião, happy hour | **Zaad** | Projeção moderada, arrumado |
| Noite fria, jantar, inverno | **Fervo** | Quente e envolvente |
| Frio ou festa, quando quer ser notado | **Black** | Presença forte (1 a 2 borrifos) |
| **Noite quente, encontro** | *(lacuna)* | Nada serve bem hoje |

## Como as peças se relacionam

```
Fresco / calor          Verde ── Rosmarino ── Zaad        (71–74% parecidos)
                                                  │
Presença / meia-estação                         Black     (musgoso, forte)
                                                  
Quente / frio                                   Fervo     (único diferente)
```
